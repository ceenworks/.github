# Ceenworks

Ceenworks is a software development portfolio focused on practical delivery for web apps, backend APIs, automation workflows, desktop tools, and mini program projects.

The repositories here are designed as public delivery samples for freelance clients. They show project structure, README quality, runnable demos where possible, and the kind of handoff documentation clients can expect.

## Showcase Repositories

- [fullstack-admin-dashboard](https://github.com/ceenworks/fullstack-admin-dashboard): full-stack dashboard demo with a Node.js API and browser UI.
- [ai-workflow-automation](https://github.com/ceenworks/ai-workflow-automation): CSV automation pipeline for classifying tickets and generating reports.
- [api-integration-starter](https://github.com/ceenworks/api-integration-starter): Java API integration starter with tests.
- [desktop-productivity-tool](https://github.com/ceenworks/desktop-productivity-tool): C# desktop productivity tool skeleton.
- [mini-program-demo](https://github.com/ceenworks/mini-program-demo): WeChat Mini Program project skeleton.

## Services Represented

- Full-stack web application development
- Backend API design and integration
- Business workflow automation
- AI-assisted application workflows
- Desktop application development
- Mini program development
- Bug fixing, refactoring, and handoff documentation

## Working Style

Projects are structured for clear review, practical setup, and maintainable handoff. Each repository documents the goal, tech stack, how to run it, and what would be added in a client production version.
